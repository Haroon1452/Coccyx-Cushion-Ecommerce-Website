# Coccyx Cushion – Shopify E-commerce Store

A UK-focused e-commerce storefront specializing in ergonomic coccyx memory foam cushions, designed to provide comfortable seating support for everyday activities.

**Live Website:** https://coccyx-cushion.co.uk/

## Project Overview

Coccyx Cushion is an online retail project focused on ergonomic seating comfort products. The store presents memory foam cushions designed for use at home, in offices, during driving, and while travelling.

The storefront provides product information, product variations, bundle offers, customer information, and an online shopping experience for UK customers.
